# Java OOP Banking System

A console-based banking application built in Java demonstrating core OOP principles:
- Encapsulation
- Classes and objects
- Transaction logging
- Safe deposit/withdraw logic

## Features
- Create bank accounts with names and balances
- Deposit and withdraw funds
- View current balance
- Print full transaction history (up to 100 transactions)

## How to Run
```bash
javac BankAccount.java Transaction.java
java Transaction
